1. **Unzip file**

   * Klik kanan pada file ZIP yang kamu dapat
   * Pilih **Extract / Unzip** sampai menjadi folder biasa

2. **Pindahkan folder ke htdocs**

   * Copy atau cut folder hasil unzip tadi
   * Pindahkan ke folder:
     **C:/xampp/htdocs/**

3. **Jalankan XAMPP**

   * Buka **XAMPP Control Panel**
   * Klik **Start** pada:

     * **Apache**
     * **MySQL**

4. **Cek website**

   * Buka browser (Chrome / Edge / Firefox)
   * Ketik alamat berikut:
     **[http://localhost/learning-lite](http://localhost/learning-lite)**
   * Pastikan website bisa terbuka
     (kalau belum, jangan lanjut dulu)

5. **Buat database**

   * Buka browser dan masuk ke:
     **[http://localhost/phpMyAdmin](http://localhost/phpMyAdmin)**
   * Klik menu **New**
   * Isi nama database: **learninglite**
   * Klik **Create**

6. **Import database**

   * Klik database **learninglite** yang baru dibuat
   * Pilih menu **Import**
   * Klik **Choose File**
   * Ambil file database dari folder project:

     ```
     includes/config/
     ```

     (file berformat **.sql**)
   * Klik **Go**

7. **Selesai**

   Jika tidak ada error, berarti database sudah berhasil
   Refresh kembali:
     [http://localhost/learning-lite](http://localhost/learning-lite)**
